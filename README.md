A workout tracker powered with AI

It's a simple workout tracker that can help you a lot with 
- allowing you to put any exercise with the amount of sets and reps
- when you are done with that workout there's a quick and easy way to remove it
- using openAI it provides you with advice and tips on the excercise, sets, and reps given
- finally the push that when clicked motivates you when you are working out

Built with TypeScript, Vite, and OpenAI’s GPT-3.5 API

inspiration
- my roommate walked in while I was trying to figure out an idea for my project and he was complaining about the gym
- him complaining made me think I can help him through making this website
